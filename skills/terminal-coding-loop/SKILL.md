# Terminal Coding Loop

## Overview
Drives autonomous coding workflows directly within the terminal, executing bash commands, interpreting compile errors, and iteratively editing code until tests pass.

## Key Capabilities
- Terminal command dispatch with streaming output capture.
- Automated error parsing and traceback root-cause identification.
- Progressive verification of intermediate code changes.
