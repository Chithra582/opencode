# LSP Codebase Navigation

## Overview
Integrates with Language Server Protocol servers to inspect symbol definitions, find all references, and query compiler diagnostics across TypeScript, Rust, Go, Python, and C++.

## Key Capabilities
- Real-time compiler diagnostics and type error resolution.
- Symbol definition lookup and cross-file reference mapping.
- Workspace-wide symbol search for architectural discovery.
