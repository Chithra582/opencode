# AST-Aware Diff Patching

## Overview
Generates and verifies surgical code diffs that preserve file formatting, surrounding comments, and syntactical integrity across all major programming languages.

## Key Capabilities
- Exact substring matching and targeted block replacement.
- Conflict detection and automatic lint error prevention.
- Clean rollbacks if edits fail compiler verification.
